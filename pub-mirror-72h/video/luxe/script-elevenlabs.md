## Le parti pris

Les pubs anti-frisottis du marché se ressemblent. Elles montrent :
- un avant/après en écran partagé ;
- un test en chambre d'humidité ;
- une créatrice face caméra ;
- des cartons de promesses en couleurs vives.

C'est efficace, mais tout le monde le fait. Celle-ci prend le code des maisons de luxe :
- noir profond, lumière dorée, gros plans de matière ;
- une phrase par plan, une voix basse et lente ;
- le produit traité comme un bijou.

Elle se distingue dans le fil, elle justifie un prix premium et le nom « Mirror » devient une image : le fini miroir.

Cette comparaison s'appuie sur les codes connus de la catégorie, pas sur une analyse de leurs campagnes du moment.

## La voix à choisir dans ElevenLabs

- **Voix féminine française**, 25-40 ans, grave et posée, presque murmurée : le registre d'une pub de parfum. Dans la
  bibliothèque de voix, cherche « French », « female », « calm », « luxury », « narration » ou « soft ».
- **Modèle** : le modèle multilingue le plus récent (meilleur français).
- **Réglages de départ** :
  - Stability environ 45 % ;
  - Similarity environ 75 % ;
  - Style environ 20 % ;
  - Speed environ 0,9 (plus lent que la normale).
- **Génère chaque phrase séparément**, puis pose-la à son instant dans le montage. C'est plus simple à caler qu'un seul
  fichier.

« … ». Elle peut déborder de 0,2 s sur le silence qui suit, pas plus.
